# RP Motorcycles Services Page - Elementor Template

## Files Included

1. **rp-motorcycles-template.json** - Elementor template file
2. **rp-motorcycles-styles.css** - Additional CSS for WordPress Customizer

## Installation Instructions

### Step 1: Import the Template

1. Go to **WordPress Admin** → **Templates** → **Saved Templates**
2. Click **Import Templates**
3. Select the file `rp-motorcycles-template.json`
4. Click **Import Now**

### Step 2: Create Your Page

1. Go to **Pages** → **Add New**
2. Enter the page title (e.g., "Our Services")
3. Click **Edit with Elementor**
4. Click the **folder icon** (Add Template)
5. Go to **My Templates** tab
6. Find "RP Motorcycles Services" and click **Insert**
7. Choose whether to keep current page settings or use template settings

### Step 3: Add the CSS

1. Go to **Appearance** → **Customize**
2. Go to **Additional CSS**
3. Copy ALL content from `rp-motorcycles-styles.css`
4. Paste it into the Additional CSS field
5. Click **Publish**

### Step 4: Set Page as Full Width

1. While editing the page, click the **gear icon** (bottom left)
2. Under **Page Layout**, select **Elementor Full Width** or **Elementor Canvas**
3. Click **Update**

## Customizing Images

To change the placeholder images:

1. Click on any service card in Elementor
2. Find the image URL in the HTML widget
3. Replace the URL with your own image URL
4. Example placeholder URLs:
   - `https://placehold.co/800x400/0085FF/FFFFFF/png?text=Motorcycle+Repair`
   - Replace with your actual image URLs

## Editing Content

All content is in **Text Editor widgets** with inline styling. To edit:

1. Click on any widget in Elementor
2. Edit the HTML directly in the text editor
3. Keep the inline styles intact to maintain the design

## Troubleshooting

### Background is white instead of dark:
- Make sure you pasted the CSS in Additional CSS
- Make sure the page is using Elementor Full Width or Canvas layout
- Clear any caching plugins

### Cards not displaying correctly:
- Check that Elementor is updated to the latest version
- Try regenerating Elementor CSS: Elementor → Tools → Regenerate CSS

### Images not loading:
- The placeholder images use placehold.co
- Replace with your actual images
- Make sure your images are uploaded to WordPress Media Library
